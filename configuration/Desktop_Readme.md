Para obtener un diseño visual de pantalla similar a lo anterior solo necesitaremos de dos extensiones.

Primero instalamos Gnome Tweaks si aún no lo tenemos:

```
sudo pacman -S gnome-tweaks
```

Posteriormente necesitamos el gnome-extensions desde la tienda.

Finalmente instalamos el plugin "Dash to Panel" y "ArcMenu" desde el Gnome Extensions.

Para su configuración se puede seguir el siguiente video: https://www.youtube.com/watch?v=8IaX2BuvEqA
